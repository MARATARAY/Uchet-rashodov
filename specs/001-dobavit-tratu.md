# Добавить трату

## Для кого и зачем

Для семьи, которая ведёт учёт расходов: быстро записать трату, увидеть последние записи и общую сумму расходов за текущий месяц.

## Что должно быть

- Страница на русском языке с формой добавления траты.
- Поля формы:
  - «Сумма» — обязательное положительное число, не более двух знаков после запятой. Принимать точку и запятую как десятичный разделитель.
  - «Категория» — обязательный выбор. Начальные категории: «Еда», «Транспорт», «Дом».
  - Пункт «Добавить категорию траты» в выборе категории открывает поле названия и кнопку добавления. После добавления новая категория выбрана и доступна для следующих трат. Сам этот пункт категорией не является.
  - «Дата» — обязательная календарная дата, по умолчанию сегодня по местному времени браузера.
  - «Комментарий» — необязательный текст.
- Кнопка «Добавить трату» сохраняет запись и сразу обновляет список и итог без перезагрузки.
- После сохранения очищаются сумма и комментарий, сохраняется выбранная категория, дата возвращается к сегодняшней.
- Ошибки ввода отображаются рядом с соответствующими полями; неверная запись не сохраняется, введённые значения остаются в форме.
- Пустое или состоящее из пробелов название категории не принимается. Повторные названия после удаления пробелов по краям и без учёта регистра не создаются.
- Под формой расположен список всех трат: сумма, категория, дата и комментарий, если он указан.
- Список отсортирован по дате траты от новых к старым. При одинаковой дате последняя добавленная запись идёт первой.
- Над списком отображается «Итого за текущий месяц»: сумма записей, дата которых относится к текущему календарному месяцу и году по местному времени браузера.
- Если трат ещё нет, отображается понятное сообщение и итог 0,00. Если в текущем месяце трат нет, итог также равен 0,00.
- Траты и добавленные категории сохраняются в localStorage и восстанавливаются после обновления страницы.

## Примеры

- Ввести 2500,50, выбрать «Еда», сегодняшнюю дату, добавить комментарий «Продукты» и сохранить → под формой появляется запись с этими значениями, итог месяца увеличивается на 2500,50.
- Добавить трату 500 в категорию «Транспорт» с датой предыдущего месяца → запись появляется в списке, итог текущего месяца не меняется.
- Добавить категорию «Здоровье» → она выбрана и остаётся в списке категорий после F5.
- Повторно ввести название « здоровье » → дубликат не создаётся, показано понятное сообщение.
- Ввести сумму 0, отрицательное число, текст или число с тремя знаками после запятой → запись не добавляется, показана ошибка.
- Для проверки итога: добавить в текущем месяце 100,10 и 200,20, а в предыдущем — 50 → итог текущего месяца 300,30.
- Добавить две записи с одинаковой датой → более поздно добавленная отображается выше.

## Ограничения

- Только `index.html`, `styles.css` и `script.js`, без npm, библиотек и внешних ресурсов.
- Данные остаются в браузере; отправки в интернет, аккаунтов и синхронизации нет.
- Валюта пока не задана: показывать суммы с двумя десятичными знаками без обозначения валюты. Конвертацию валют не добавлять.
- Для расчётов хранить суммы в целых сотых долях единицы, чтобы исключить ошибки сложения дробных чисел.
- Дату траты хранить как календарную дату без смещения часового пояса.
- Пользовательский текст отображать как текст, без выполнения HTML.
- Редактирование, удаление, фильтры и экспорт не входят в эту функцию.
- Все поля и кнопки не меньше 44px по высоте; страница должна помещаться на экране шириной 375px без горизонтальной прокрутки.

## Готово, когда

- [ ] Валидная трата добавляется, и все её поля видны в списке.
- [ ] Обязательные поля и формат суммы проверяются; неверная запись не сохраняется.
- [ ] Новая категория добавляется, выбирается и сохраняется после F5; пустые и повторные категории не создаются.
- [ ] Новые по дате траты идут первыми; одинаковые даты упорядочены по моменту добавления.
- [ ] Итог включает только текущий месяц и год; пример 100,10 + 200,20 даёт 300,30.
- [ ] Пустой список и месяц без расходов отображаются корректно.
- [ ] После F5 записи, категории и итог восстанавливаются.
- [ ] Страница открывается двойным щелчком по `index.html` и работает без внешних ресурсов.
- [ ] На ширине 375px нет горизонтальной прокрутки, поля и кнопки удобны для нажатия.
- [ ] В `README.md` описаны возможности страницы и шаги проверки с примерами выше.
