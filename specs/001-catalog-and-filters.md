# Базовый каталог с поиском и фильтром

## Для кого и зачем

Для человека, который хочет быстро найти фильм, сериал или мультфильм в коротком готовом списке: увидеть карточки, сузить их по категории и по части названия и сразу понять, сколько записей подошло.

## Что должно быть

- Страница на русском языке. В ней заранее лежит каталог из 9 карточек. Добавлять, менять и удалять карточки нельзя.
- У каждой карточки видны название и категория. Категории только три: «Фильмы», «Сериалы», «Мультфильмы».
- Начальный состав:
  - Фильмы: «Начало», «Интерстеллар», «Матрица».
  - Сериалы: «Друзья», «Во все тяжкие», «Игра престолов».
  - Мультфильмы: «Шрек», «Король Лев», «Холодное сердце».
- Над карточками — поле «Поиск» и четыре кнопки фильтра: «Все», «Фильмы», «Сериалы», «Мультфильмы». Одновременно активна только одна кнопка. При открытии страницы активна «Все», поле поиска пустое.
- Поиск идёт по названию: без учёта регистра, по вхождению части слова. Пробелы по краям не мешают поиску. Категория в поиске не участвует.
- Фильтр и поиск работают вместе: сначала категория, затем название. «Все» не отсекает категорию.
- Рядом виден счётчик «Найдено: N». N — число карточек, которые остались на экране. Счётчик меняется сразу при вводе и при смене фильтра, без перезагрузки.
- Если ничего не подошло, карточек нет и показано «Ничего не найдено», счётчик «Найдено: 0».
- Очень длинный запрос не ломает страницу и даёт тот же пустой результат.
- Повторный одинаковый запрос и повторное нажатие уже активной кнопки не меняют список и счётчик.
- Очистка поиска при том же фильтре возвращает все карточки этой категории. «Все» и пустой поиск снова показывают 9 карточек.
- После F5 снова активна «Все», поиск пустой, видны все 9 карточек и «Найдено: 9». Отдельного сохранения поиска не требуется: каталог постоянный и лежит на странице.

## Примеры

- Открыть страницу → 9 карточек, активна «Все», «Найдено: 9».
- Нажать «Сериалы» → видны «Друзья», «Во все тяжкие» и «Игра престолов», «Найдено: 3». «Начало» и «Шрек» скрыты.
- Нажать «Фильмы» и ввести «тер» → виден только «Интерстеллар», «Найдено: 1».
- При фильтре «Фильмы» ввести «  начало  » → виден «Начало», «Найдено: 1».
- При фильтре «Мультфильмы» ввести «шрек» → виден «Шрек», «Найдено: 1».
- При фильтре «Фильмы» ввести «Шрек» → карточек нет, текст «Ничего не найдено», «Найдено: 0».
- Стереть поиск, оставив «Фильмы» → снова три фильма и «Найдено: 3». Нажать «Все» → 9 карточек и «Найдено: 9».
- Ввести строку из 200 символов «ааа…» → «Ничего не найдено», «Найдено: 0», страница без горизонтальной прокрутки на ширине 375px.
- Нажать F5 → снова 9 карточек, «Все» и «Найдено: 9».

## Ограничения

- Только `index.html`, `styles.css` и `script.js`, без npm, библиотек и внешних ресурсов. Картинки, трейлеры и запросы в интернет не нужны.
- Каталог постоянный, из 9 названий выше. Новые карточки, свои категории, избранное, сортировка и сохранение фильтра в браузере не входят в эту функцию.
- Названия показывать как текст, без выполнения HTML.
- Кнопки и поле поиска не ниже 44px. На ширине 375px нет горизонтальной прокрутки: карточки идут друг под другом, фильтры можно нажать пальцем.

## Готово, когда

- [ ] При открытии видны 9 карточек, активна «Все», счётчик «Найдено: 9».
- [ ] У карточки читаются название и одна из категорий: «Фильмы», «Сериалы», «Мультфильмы».
- [ ] Кнопки «Все», «Фильмы», «Сериалы», «Мультфильмы» оставляют только свою категорию; «Все» показывает весь каталог. Активна одна кнопка.
- [ ] Поиск по части названия без учёта регистра и с пробелами по краям сужает уже отфильтрованный список.
- [ ] Счётчик совпадает с числом видимых карточек и для 9, и для 3, и для 1, и для 0.
- [ ] Пустой результат показывает «Ничего не найдено» и «Найдено: 0», в том числе на запросе длиннее обычного слова.
- [ ] Очистка поиска и возврат к «Все» снова дают 9 карточек. После F5 состояние то же, что при первом открытии.
- [ ] Страница открывается двойным щелчком по `index.html` и работает без интернета.
- [ ] На ширине 375px нет горизонтальной прокрутки, поле и кнопки удобно нажимать.
- [ ] В `README.md` описано, что умеет страница, и проверка по примерам выше.
