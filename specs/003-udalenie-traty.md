# Удаление ошибочной траты

## Для кого и зачем

Для пользователя, который ошибся при вводе: удалить отдельную запись и затем при необходимости внести правильную через существующую форму.

## Что должно быть

- У каждой записи в списке есть кнопка «Удалить» высотой не менее 44px, доступная с клавиатуры и на телефоне.
- Доступное название кнопки позволяет отличить запись: содержит категорию, сумму и дату.
- Перед удалением показывать подтверждение с категорией, суммой и датой выбранной траты. Действия: подтвердить удаление или отменить.
- При отмене запись, порядок списка и итоги остаются прежними.
- При подтверждении удалять только выбранную запись, даже если есть полностью одинаковые траты или список отсортирован иначе, чем порядок добавления.
- Сначала сохранять результат в localStorage. После успешного сохранения обновлять список, общий итог и суммы категорий без перезагрузки.
- После F5 удалённая запись не восстанавливается.
- Удаление траты не удаляет её категорию и не очищает введённые в форме значения.
- После удаления последней записи отображать существующее сообщение пустого списка и нулевые итоги.
- После удаления сообщать об успехе через доступное уведомление и переводить фокус на соседнюю кнопку удаления, а при пустом списке — на поле суммы.
- Если сохранение не удалось, показать понятную ошибку, оставить запись и итоги без изменений.

## Примеры

- Есть две траты «Еда» за текущий месяц: 100,10 и 200,20. Удалить первую и подтвердить → остаётся 200,20, общий итог и итог еды равны 200,20.
- Нажать «Удалить» и отменить → обе записи и итог 300,30 остаются.
- Создать две одинаковые записи, удалить одну → остаётся ровно одна запись.
- Удалить трату предыдущего месяца → она исчезает из списка, итоги текущего месяца не меняются.
- Удалить последнюю трату → пустой список, общий итог 0,00, все категории остаются с нулевыми суммами.

## Ограничения

- Только удаление одной выбранной траты; массовое удаление, редактирование и корзина не входят в эту функцию.
- Подтверждение предупреждает, что удаление нельзя отменить.
- Сохраняются существующие данные localStorage, включая записи, созданные до добавления этой функции. Если для точного выбора записи нужны идентификаторы, обеспечить совместимость с прежними записями.
- Сохраняются правила локального хранения, точных денежных расчётов и адаптации для ширины 375px.
- Проверки удаления выполнять на вымышленных тестовых данных в изолированном хранилище.

## Готово, когда

- [ ] У каждой записи есть доступная кнопка удаления не ниже 44px.
- [ ] Подтверждение описывает нужную запись; отмена ничего не меняет.
- [ ] Удаляется ровно выбранная запись, включая случаи одинаковых записей и разного порядка дат.
- [ ] Общий итог и сводка категорий сразу пересчитываются правильно.
- [ ] Удаление записи другого месяца не меняет текущие итоги.
- [ ] После F5 удалённая запись не возвращается, остальные записи и категории сохранены.
- [ ] Удаление последней траты возвращает пустое состояние и нулевые суммы.
- [ ] При ошибке localStorage запись и итоги остаются прежними, показана ошибка.
- [ ] Значения в форме не сбрасываются; фокус после удаления остаётся в понятном месте.
- [ ] Старые сохранённые записи тоже можно удалить.
- [ ] Кнопки доступны на ширине 375px без горизонтальной прокрутки.
- [ ] В README.md описаны удаление и шаги проверки.
